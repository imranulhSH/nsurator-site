Let AI find your films

Once connected, one sentence is enough for an AI tool to find a film, start it or build a collection. What it can see and change is up to you, one permission at a time.

  • 6 min read
  • For Mac · Pro

On this page

  1. Before you start
  2. Turn on the connection, then grant permissions
  3. Hook up your AI tool
  4. Things you can ask today
  5. What it can't do yet

Before you start

  • It's a Pro feature on the Mac. On Free you can still open the page, but connected tools only get "This is a Pro feature". There are no AI agents on iPhone or iPad.
  • It only connects on this Mac. Nsuve listens on the loopback address 127.0.0.1, so nothing on your network or the internet can reach it. AI tools come in through the nsuve command-line tool that ships with Nsuve and never touch your library files.
  • Private Space is always excluded, even when it's unlocked.
  • Results may leave this Mac. Nsuve hands a tool only what you've opened up to it. Whether the tool sends those results on to a remote model is up to the tool.

Turn on the connection, then grant permissions

  1. In the workbench sidebar, under Tools, click AI Agents.
  2. Turn on "Allow AI & automation to connect". When the line below reads Running · 127.0.0.1 with a port number, it's on.
  3. Under Permissions, turn on only what you need right now. All seven switches start off; for your first try, turn on just Read ordinary catalog.
PermissionLets a tool
Read ordinary catalogSearch videos, people, tags, collections and file paths
Read playback stateSee what's playing, the progress and the queue
Control playbackOpen, play, pause, stop, seek, skip, change the volume and move through the queue
Edit catalog detailsChange favorites, ratings, tags, people, notes and collections; never moves files
Person recognitionAnalyze faces, scan the library, confirm or dismiss suggestions
Archive filesMove Inbox videos into the library by your archive rules, previewing first
Clean up duplicatesMove surplus duplicates to the Trash; never a permanent delete

Show methods next to each switch lists exactly which tool methods it unlocks. Turning off the main switch disables every permission at once but remembers how each was set; meanwhile every call a tool makes is refused.

Hook up your AI tool

Connect a tool has ten presets: Claude Code, Codex, Cursor, Windsurf, VS Code, Gemini CLI, Qoder, WorkBuddy, Kimi CLI and Grok. The ones installed on this Mac are listed under Detected; the rest wait under Other supported tools and move up once installed. Nsuve never edits another app's settings. It gives you the command or config, and you add it.

  1. Select the tool you want to connect.
  2. For command-line tools such as Claude Code, Codex and Gemini CLI, click Copy command and run it once in Terminal. It reconnects on every launch after that.
  3. Cursor, Windsurf and WorkBuddy use a config file. Click Copy config, merge it into the file named on the page, then restart the tool; Reveal config file finds it in Finder. For Cursor you can also just click Install in Cursor.
  4. Back in the tool, ask a read-only question to check the connection.

For Claude Code, the copied command looks roughly like claude mcp add --transport stdio --scope user nsuve -- …/nsuve mcp serve --client claude. The middle part is the path to the nsuve tool on your Mac, so copy it from your own app rather than from here.

Access tokens

By default every tool shares one access token, and the page shows only its last four characters. If you think it has leaked, click Rotate; connected tools pick up the new one on their next call. You can also Issue own token for a single tool, which lets you make that tool Read-only or Revoke it on its own.

Things you can ask today

Start with a read-only question whose answer is easy to check. Each example lists the permissions it needs.

  • "Which Christopher Nolan films are in my library? Just list them, don't change anything." (Read ordinary catalog)
  • "What arrived on the NAS this week?" (Read ordinary catalog)
  • "How many videos in the Inbox haven't been archived yet?" (Read ordinary catalog)
  • "Are there any duplicate files in my library? Show me first." (Read ordinary catalog)
  • "What haven't I finished watching? List them and I'll pick one to resume." (Read ordinary catalog and Control playback)
  • "What's playing right now, and how long is left?" (Read playback state)
  • "Pause", "skip ahead 10 minutes", "turn it down a bit" (Control playback)
  • "Put Interstellar, Dune: Part Two and Blade Runner 2049 in a collection called Weekend sci-fi." (Edit catalog details)

Edits that touch 10 films or fewer happen right away. Afterwards, check Recent activity at the bottom of the page: each call is written up as one sentence saying which tool did what, and how it went.

What it can't do yet

  • Big batches and moving files. Changing more than 10 films at once, moving files (archiving, sending to the Trash) or re-recognizing a whole folder all need you to click Allow in Nsuve. That confirmation card hasn't shipped yet, so these requests won't run for now. With Archive files or Clean up duplicates on, an AI tool can show you a preview, but actually moving files waits for the card.
  • Fixing recognition. The permission that lets AI re-match films, refresh details, change posters and write NFO files will be added to the list later.
  • Adding sources. AI can't add a source that needs a password or sign-in; add those yourself in the app.
  • Private Space. AI never sees it, unlocked or not.
To stop

Turn off "Allow AI & automation to connect" and every tool's calls are refused. To stop just one tool, issue it its own token, then Revoke it.
